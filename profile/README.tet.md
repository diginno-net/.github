Diginno mak estudiu implementasaun ne'ebé baze iha Hanoi, Vietnam — harii sistema operasaun reál ho **Lark (LarkBase)** · **n8n** · integrasaun sistema no AI. Ami troka serbisu Excel manual ba sistema automátiku, no dadus ne'ebé nakfahe ba dashboard tempu-reál — ami fó prioridade ba buat ne'ebé la'o duni iha production, la'ós de'it demo furak.

## Saida mak ami harii

| Área | Konteúdu |
|---|---|
| **Sistema Lark / LarkBase** | CRM · HR, presença no saláriu · armazém no POD · finansas no e-Invoice · aprovasaun · KPI/komisaun — sai sistema operasaun internu kompañia nian |
| **Automátiku n8n** | workflow production atus-barak: liga sistema sira, hamenus serbisu manual, mantein kualidade dadus |
| **Integrasaun** | LarkSuite · Pancake · TikTok Shop · Shopee · KiotViet · NhanhVN · MISA · gateway pagamentu · API própriu |
| **Dadus no relatóriu** | PostgreSQL/DWH · ETL · dashboard tempu-reál · relatóriu reseita – P&L |
| **AI ba operasaun** | AI agent no chatbot atendimentu kliente · AI gateway internu · automasaun ho aprovasaun umanu no audit log |

**Produtu no ferramenta:** ZaloCRM (jestaun konta Zalo barak + AI atendimentu kliente, PWA) · DigiHub (kapa ligasaun no sinkronizasaun dadus ba SME).

## Tanbasá hili Diginno

- **Espesializasaun kle'an iha Lark/LarkBase** — ba operasaun no dezeñu dadus
- **n8n nivel production** — workflow barak, sistema barak, ho monitorizasaun
- **Business-first** — prosesu, KPI no operasaun reál lai, ferramenta tuir fali
- **Mentalidade production** — aprovasaun, log, permisaun, entregá no manutensaun husi loron dahuluk
- **Harii husi projetu reál** — la'ós esperiénsia internu
- **Parseiru tempu-naruk** — implementa → treinu → opera → hadi'a beibeik
