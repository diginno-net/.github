Diginno 是一家位于越南河内的落地实施工作室，用 **Lark（飞书）/LarkBase**、**n8n**、系统集成与 AI 搭建真正在用的运营系统：把「手工 Excel」变成「自动化系统」，把「分散数据」变成「实时看板」。我们看重的是能上线、能运营、能产生业务价值，而不是好看的演示。

## 我们做什么

| 领域 | 内容 |
|---|---|
| **Lark / LarkBase 运营系统** | CRM · 人事考勤薪酬 · 仓储与 POD 回单 · 财务与电子发票 · 审批流 · KPI/提成 — 打造企业内部的操作系统 |
| **n8n 自动化** | 数百条生产级工作流：系统间同步、减少手工操作、数据质量校验 |
| **系统集成** | LarkSuite · Pancake · TikTok Shop · Shopee · KiotViet · NhanhVN · MISA · 支付网关 · 自有 API |
| **数据与报表** | PostgreSQL/DWH、ETL、实时看板、营收与 P&L 报表 |
| **AI 运营** | AI 助手与客服机器人、内部 AI 网关、带人工审批与操作日志的自动化 |

**产品与工具：** ZaloCRM（多账号 Zalo 管理 + AI 客服，PWA）· DigiHub（面向中小企业的连接与数据同步层）。

## 为什么选择 Diginno

- **深耕 Lark/LarkBase** — 运营系统与数据设计的专业积累
- **生产级 n8n** — 多工作流、多系统、可监控
- **业务优先** — 先流程与 KPI，再谈工具
- **生产思维** — 审批、日志、权限、交付与可维护性从第一天就纳入设计
- **来自真实交付项目** — 而非内部试验
- **长期陪跑** — 实施 → 培训 → 运营 → 持续优化

## 我们的工作方式

<p align="center"><img src="https://raw.githubusercontent.com/diginno-net/.github/main/profile/assets/how-we-work.svg" alt="我们的工作方式：理解 → 设计 → 实施 → 引入 AI → 运营" width="100%"></p>
